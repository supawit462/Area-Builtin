# Area Built-in — Website

Static one-page site for an interior design & built-in furniture studio (Dark & Gold luxury theme).

Files: `index.html`, `styles.css`, `script.js` — no build step. Open `index.html` in a browser, or host on GitHub Pages / Netlify.

Sections: Hero, About, Featured Projects, Why Choose Us + Reviews, 9-step Process, Contact (form opens the visitor's email app addressed to contact@builtinasset.com).
